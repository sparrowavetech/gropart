# Indian SMS for Botble CMS

India-focused commercial SMS plugin for Botble CMS.

## Providers
- MSG91
- Fast2SMS
- 2Factor
- SMSCountry
- Kaleyra
- Custom India HTTPS Gateway

## Features
OTP verification, ecommerce customer/admin notifications, order status SMS, templates, delivery logs, queue/retry, fallback gateways, DLT fields, health diagnostics and single-domain activation.

## India phone formats
- 9876543210
- 919876543210
- +919876543210

## DLT
Production SMS in India may require registered sender IDs, Principal Entity IDs and approved templates. Configure the values supplied by your SMS provider.

## Ashikul License Panel
Version 1.0.8 uses the Ashikul License Panel API for activation, validation and domain release.
- Product ID: `indian-sms-gateway`
- One-domain activation is enforced by the license server.
- License status is checked every 12 hours.
- A 72-hour offline grace period is available after a successful validation.
- License keys are encrypted in Botble settings and are never displayed again.


## License integration
The Ashikul License Panel is integrated into the complete Indian SMS plugin. The dashboard menu and all original functionality remain available; protected routes require an active license.

## Free trial

A fresh installation can send up to 100 successfully accepted SMS without a license.
Failed SMS requests do not use the allowance. After the allowance is exhausted,
a valid Ashikul License Panel key is required to continue sending.
